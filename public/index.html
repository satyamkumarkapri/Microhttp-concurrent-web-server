Three Concurrency Models

Compare real implementations — not simulations

①

Single-Threaded

Baseline Model

One client at a time. The simplest architecture — pure socket accept/read/write loop. Useful for benchmarking overhead of concurrent modes.

./microhttp --mode single --port 8080
OS: socket, bind, listen, accept
Recommended
②

Thread Pool

Concurrent Model

Pre-created worker threads consume jobs from a bounded queue. Backpressure prevents unbounded memory usage. Handles many simultaneous clients.

./microhttp --mode threadpool --workers 8
OS: pthread_create, mutex, cond_wait
③

epoll Event Loop

Linux Event-Driven

Single thread manages thousands of non-blocking sockets via the Linux epoll interface. O(active events) complexity. Integrated timerfd for idle timeouts.

./microhttp --mode epoll --port 8080
OS: epoll_create1, epoll_ctl, epoll_wait

HTTP/1.1 Features

⚡

Streaming Parser

Handles partial recv() correctly. Parser accumulates bytes across multiple system calls.

🔒

Path Security

realpath() canonicalization blocks directory traversal, encoded attacks like %2F.

♻️

Keep-Alive

HTTP/1.1 persistent connections. Multiple requests per TCP connection.

📦

Range Requests

RFC 7233 Range: bytes=start-end. Returns 206 Partial Content with Content-Range.

🕐

Conditional GET

If-Modified-Since support. Returns 304 Not Modified for unchanged resources.

⏱️

Idle Timeout

timerfd-based idle connection detection. Sends 408 and frees resources cleanly.

🛑

Graceful Shutdown

SIGINT/SIGTERM via signalfd. Drains in-flight requests, joins threads, frees memory.

🚀

Zero-Copy Transfer

sendfile() syscall transfers file data kernel→socket without user-space copy.

OS Concepts Demonstrated

Week 1

Syscall Boundary

socket(), bind(), listen(), accept() — transitioning from user mode to kernel mode for network I/O

Week 2

Memory Model

Explicit heap ownership. connection_t allocated per-connection, freed by exact owner thread.

Week 3

Parsing / I/O Streams

Streaming HTTP parser handles partial recv() — TCP delivers bytes, not messages.

Week 4

Thread Pool

pthread_create + bounded queue + mutex/condvar. Workers drain a job queue concurrently.

Week 6

Signals + timers

signalfd + timerfd on Linux. Signal-safe shutdown. Idle timeouts via epoll-integrated timers.

Week 9

File Descriptors

stat(), fstat(), open(), sendfile() — zero-copy file transfer. Range requests with lseek().

Week 10

epoll

epoll_create1, epoll_ctl, epoll_wait. O(active) event polling. Edge-triggered mode.

Week 11

Deadlock Avoidance

Single lock order, bounded queue prevents unbounded resource use. Race-free shared state.
